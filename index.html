Learning Engine n8n

A personal learning tool for organizing source-linked notes and retrieving learning information.

How it works

The owner submits a request through a designated Google Drive folder. A locally operated n8n workflow sends it to a local learning service, then writes the result back to Drive. Functions include service checks, learning-state queries, retrieval, and submitting material for review.

New memory candidates require local review before becoming authoritative records. Retrieved and generated information should be checked against original sources.

Personal use

This integration is intended for its owner's personal use. This public website provides information only: it offers no public sign-up and no access to the owner's learning records or local service.
