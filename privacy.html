Privacy policy

This policy describes the personal Learning Engine n8n integration and this information website.

Google Drive access

The workflow reads metadata and contents of request files in its configured Drive folder, writes results back to those files, and updates filenames. Requests and results may contain learning notes, questions, source excerpts, topics, timestamps, and retrieved information.

The configured OAuth permission allows broader Drive access than the workflow's folder filter. That filter is an application behavior, not a restriction on the credential's permissions.

Processing and storage

Request and result files remain in the authorized Google Drive account. The owner's local n8n instance processes them, and the local learning service stores results and learning records. Local models may generate candidates for review. Workflow execution records and backups may also contain processed information.

If the owner uses a connected chat application to submit or read files, that application also processes the selected content under its own settings and policies. This information website does not collect Google authorization tokens or submit learning requests.

Purpose and sharing

The integration uses information for the owner's requested learning functions. It does not sell learning data, use it for advertising, or use it to train generalized AI models. Data passes through the services the owner chooses to use, including Google Drive and, when invoked, the connected chat application.

The use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

The owner can revoke access in Google Account settings and stop the local workflow. Revocation stops future authorized access but does not erase existing Drive files, local records, execution history, or backups. These copies must be deleted separately in their respective storage systems. There is no single automatic deletion deadline across all stores.

Website hosting

This static website is hosted by GitHub Pages. It contains no application analytics scripts, advertising, or forms. The hosting provider may process standard connection information under its privacy statement.
