06Policies

Privacy policy.

Privacy information for this information website, its hosting, and the retired Learning Engine integration.

Revision: 13 October 2026

Scope

This policy covers the Quiet Field Notes information website hosted on GitHub Pages and historical notices for the retired Learning Engine Google Drive/n8n integration. This website does not provide public signup, a paid service, or access to private learning records.

Website hosting

This static website is hosted by GitHub Pages. Its source includes no analytics scripts, advertising, submission forms, public login, or visitor-profile storage. It does not collect Google authorization tokens or submit learning requests.

The absence of application analytics does not mean that the hosting provider processes no connection data. GitHub may process connection and usage information under its privacy statement. This page does not assert specific hosting identifiers, cookies, or retention periods that have not been verified.

Separate Sites display version

A separate display pilot is hosted on ChatGPT Sites. Visiting this GitHub Pages website does not automatically send you to that pilot. If you choose to visit it, its platform processing is described in the display pilot’s privacy notice. No Sites analytics code is included in these GitHub Pages files.

Retired Google Drive/n8n integration

The owner confirmed on 13 October 2026 that the legacy Google Drive/n8n bridge is no longer in use. Its earlier documentation described reading request-file metadata and contents, writing results and filenames in a configured Drive folder, and processing learning notes, questions, source excerpts, topics, timestamps, and retrieved information.

The historical OAuth permission was broader than the workflow’s folder filter. That filter was application behavior, not a credential permission boundary. Retirement does not establish that authorization has been revoked or that permissions have been narrowed.

Historical processing and storage

The earlier integration policy described request and result files in the authorized Google Drive account, local n8n processing, local learning records, model-generated candidates for review, and possible copies in execution history and backups. These are historical descriptions, not a verified inventory of every current service or store.

Retirement does not establish that those copies have been deleted. If the owner uses a connected chat application to submit or read files, that application processes the selected content under its own settings and policies. This information website does not provide those processing functions.

Purpose and sharing of historical integration data

The earlier integration policy stated that data was used for the owner’s requested learning functions and was not sold, used for advertising, or used to train generalized AI models. That statement describes the operator’s stated use, not every third-party provider’s practices.

The use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements. Retiring the bridge does not remove this commitment for information previously received through those APIs.

Retention and control

The owner can revoke Google access. Revocation stops future authorized access; it does not erase existing Drive files, local records, execution history, or backups. Those copies require separate deletion in their respective systems. No automatic deletion deadline or complete deletion workflow is asserted here.

Contact and external links

The operator’s public project identity is hutianjie12345. General questions may be raised in the public project tracker. Do not include private notes, credentials, or account data. Private learning-data deletion remains an action for the owner in the relevant storage systems.

Following an external link opens a separate service governed by that service’s policies. This website does not offer a private contact form.
