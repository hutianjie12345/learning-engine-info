# Quiet Field Notes

Public information website at https://learning.quietfieldnote.com, hosted by GitHub Pages from main / (root).

Eight static HTML pages share assets/site.css and assets/mark.svg. No application backend, account system, forms, payments, or analytics SDK is included. The production CNAME remains learning.quietfieldnote.com.

The redesign is derived from the reviewed Sites pilot source 630743804b7283bb21800d5b09c27183e86e6420. Pages-specific policy wording and the owner-confirmed retirement of the legacy Drive/n8n bridge are recorded in this release. The separate display pilot remains at https://sites-pilot.quietfieldnote.com. Neither host synchronizes automatically with the other.

Keep the existing index.html, privacy.html, and terms.html routes. The 404.html page provides the Pages error page; .nojekyll disables Jekyll processing.

General questions: https://github.com/hutianjie12345/learning-engine-info/issues. Do not post private notes or credentials.
